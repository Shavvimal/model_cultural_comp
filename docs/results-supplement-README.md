# Corrected paper results and historical provenance

This separate supplement supplies the aggregate artifacts named in the corrected
paper. It contains 91 regenerated CSVs, the seed-angle log, and the historical
trace_coding.json. The manifest records their exact sizes, hashes and roles.

The old trace_coding.json contains counts and model-output excerpts from the
submitted eight-coder analysis. It is preserved as historical evidence; it is NOT
the current five-panel coding and is not consumed by the corrected replay.
Current trace aggregates are in trace_coding_2026.csv, trace_coding_headline_2026.csv,
trace_agreement_2026.csv and the related diagnostic CSVs.

To inspect outputs, extract into a separate directory. To reproduce them, use the
source repository's docs/REPRODUCING.md, the separate frozen response archive and
locally licensed IVS inputs. This supplement replaces none of those inputs.
It contains no survey respondent records, fitted binaries or bootstrap draws.
